# Pedido não recebido
<!-- id: pedido-nao-recebido | acoes: troca, reembolso, escalar -->
> Política fictícia criada para este projeto.

## Investigação
Quando o cliente informa que não recebeu o pedido, abrimos uma investigação com a transportadora em até 2 dias úteis. Se o rastreio indica "entregue" e o cliente não recebeu, a investigação leva até 5 dias úteis.

## Resultado da investigação
Se o pedido for localizado, informamos a nova data de entrega. Se não for localizado, o cliente escolhe entre o reenvio do produto sem custo ou o reembolso integral (ver a política de reembolso).

## Quando escalar
Casos com suspeita de fraude na entrega ou com mais de uma ocorrência para o mesmo cliente são encaminhados para um especialista.
